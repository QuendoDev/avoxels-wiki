Esta es la wiki oficial de **Avoxels**, para jugadores, creadores de modpacks y creadores de addons. Está en inglés y en español; si una página aún no está traducida, se muestra la versión en inglés.

## Cómo se hacen las páginas

- Las **páginas de referencia** se generan automáticamente a partir de los datos del propio mod cada vez que cambian, así que siempre coinciden con la versión actual.
- Las **guías y explicaciones** se escriben a mano.
- Las páginas generadas también pueden llevar notas escritas a mano. Esas notas se guardan aparte del texto generado, así que las actualizaciones nunca las borran.
